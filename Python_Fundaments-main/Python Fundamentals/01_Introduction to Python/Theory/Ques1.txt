Introduction to Python and its Features (simple, high-level, interpreted 
language).

Ans:
Python is a programming language that was created between the year of 1985 to 
1990 by Dutch developer Guido van Rossum. Python is an interpreted, 
object-oriented, high-level language with dynamic semantics.

Features in Python

1. Free and Open Source
2. Easy to code
3. Easy to Read
4. Object-Oriented Language
5. GUI Programming Support
6. High-Level Language
7. Large Community Support
8. Easy to Debug
9. Python is a Portable language
10. Python is an Integrated language
11. Interpreted Language: 
12. Large Standard Library 
13. Dynamically Typed Language
14. Frontend and backend development
15. Allocating Memory Dynamically
